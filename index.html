내 책 편집실

회원가입 없이 사용하는 개인 편집기야. 수정 내용은 이 브라우저에 임시 저장되고, GitHub 홈페이지에 반영하려면 아래 「수정된 index.html 다운로드」로 파일을 받아서 저장소에 다시 올리면 돼. 이 버튼은 방문자에게도 보일 수 있지만 방문자의 편집이 네 GitHub 사이트를 바꾸지는 않아.

메인 화면 내용

사이트 분위기 변경

큰 음악은 파일 전체가 HTML에 들어가 매우 무거워질 수 있어. GitHub에 music.mp3를 따로 올리고 음악 주소에 music.mp3를 입력하는 걸 추천해. 브라우저 정책상 음악은 방문자가 재생 버튼을 눌러야 시작돼.

작품과 장면 관리

문단 사이는 빈 줄로 구분해. 대사를 말풍선으로 만들려면 문단 맨 앞에 [아자엘] [파놉테스] [아르비테르]처럼 적으면 돼. 표시만 화자 이름으로 바뀌고, 일반 지문은 그대로 남아.

저장과 GitHub 배포

① 먼저 「변경사항 저장」을 눌러 편집 내용을 보관해. ② 「수정된 index.html 다운로드」로 완성 파일을 받아. ③ GitHub 저장소의 index.html을 그 파일로 교체하고 Commit하면 사이트에 반영돼.

사용 중인 브라우저 저장 공간에 문제가 생겨도 복구할 수 있도록 JSON 백업을 가끔 받아둬. 이 사이트에는 회원가입·초대 코드·공개 글 작성 권한이 없어.
